Adding images

GitHub Pages is static hosting, so the old server-side upload/delete API cannot run here. Add your images to the repository instead.

  1. Open your GitHub repository.
  2. Open the images folder.
  3. Choose Add file → Upload files and upload your JPG/PNG/WebP images.
  4. Edit images.json and add each filename, for example {"name":"photo1.jpg"}.
  5. Commit the changes. GitHub Pages will publish them automatically.

Example images.json

[
  {"name":"photo1.jpg"},
  {"name":"photo2.png"},
  {"name":"photo3.webp"}
]
IMPORTANT

This password is not true server security

The password gate is browser-side because GitHub Pages cannot run the original Express session/authentication server. Anyone who can access the repository can inspect the site files, and images committed to the repository are directly accessible by URL. Do not use this version for sensitive/private photos.
